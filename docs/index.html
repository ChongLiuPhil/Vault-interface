Vault Interface
Public Metadata Contract

让项目能够公开描述，但不暴露私人内容。

Vault Interface 提供与提供商无关的公共元数据 Schema、模板和验证器。它连接项目与公共生态，但不包含私人 Vault、原创作品或部署凭据。

它负责什么

公共接口

定义项目、网站、发布状态和兼容性所需的最小公共元数据。

可验证

提供模板和验证器，使项目能够在提交和发布前检查结构。

与提供商无关

接口不绑定某一家 Vault、云平台或出版服务。

隐私边界清晰

不保存私人注册表、研究记录、工作记忆、部署清单、凭据或未公开材料；private repository 的 locator 也不是必需公共元数据。

在完整体系中的位置

新项目的默认基线是 完整 AHICP + 完整 PPF + Vault Interface + 项目自身内容。AHICP 负责探究与创作治理，PPF 负责源文件到出版的生命周期，Starter 负责组合、采用和升级，而 Vault Interface 只负责公共元数据适配。

给人类和 AI agent 的边界

阅读公共接口和体系链接，不等于获得私人项目状态的访问权。AI agent 必须先阅读 ecosystem.yaml 和统一 Agent 调取契约，再根据明确的人类授权调取私人状态。未发布原创内容默认保持 private。

Public Metadata Contract

Describe projects publicly without exposing private work.

Vault Interface provides provider-neutral public metadata schemas, templates, and validators. It connects projects to the public ecosystem without containing a private vault, original work, or deployment credentials.

What it does

Public contract

Defines the minimum public metadata needed to describe a project, website, publication state, and compatibility.

Inspectable

Provides templates and validators so projects can check structure before submission and publication.

Provider-neutral

The interface is not coupled to a particular vault, cloud platform, or publishing service.

Clear privacy boundary

It contains no private registry, research notes, working memory, deployment inventory, credentials, or unpublished material; a private repository locator is not required public metadata.

Its place in the full stack

The default new-project baseline is full AHICP + full PPF + Vault Interface + project-owned content. AHICP governs inquiry and creation, PPF governs the source-to-publication lifecycle, the Starter composes and upgrades the layers, and Vault Interface supplies only the public metadata adapter.

Boundary for humans and AI agents

Reading the public contract and ecosystem links does not grant access to private project state. An AI agent should read ecosystem.yaml and the canonical agent retrieval contract first, then retrieve private state only under explicit human authorization. Unpublished original work is private by default.

Continuous Web and Cloudflare belong to the project publication layer. Unpublished or transitional pages default to restricted/authenticated access; repositories store only an access-policy reference, never passwords, tokens, private keys, or other secrets. If Cloudflare requires human UI action, the agent must provide numbered UI steps, completion evidence, verification, and rollback.
